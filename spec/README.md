# Zoho's OpenAPI documents

`books/` holds the OpenAPI 3.0 documents Zoho publishes for the Zoho Books API v3,
unmodified, as downloaded from <https://www.zoho.com/books/api/v3/openapi-all.zip>
(linked from <https://www.zoho.com/books/api/v3/introduction/>) on 2026-11-15.
They are Zoho's work and are kept here so the generated code can be reproduced.

To update them, replace the files with a fresh download and run `bun run generate`.
The corrections the generator applies to these documents are listed in the README.
